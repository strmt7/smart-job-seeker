# Caveman

Apply this on every task. Limit reads and output to relevant evidence, batch
independent work, and avoid repeating unchanged checks. Preserve exact names,
numbers, negations, uncertainty, permissions, failures and progress updates.
Use normal grammar and sufficient detail in user messages, documentation and
code. This is an agent workflow only; it changes no product behavior.

Default to brief, direct user-facing responses. Do not narrate routine use of
this skill or any current or future repository tool, workflow, protocol or skill.
Explain tool details only when requested, needed for a material finding or
blocker, or required by higher-priority instructions. Preserve required progress
updates and essential evidence, uncertainty, failures and permission boundaries.
Prioritize product progress, reuse verified evidence and avoid redundant plans,
searches and tests; token efficiency must not weaken implementation or checks.
