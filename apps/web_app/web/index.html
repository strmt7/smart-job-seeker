Search the wider web

Use FreeSerp, Wiby, or a SearXNG-compatible instance with JSON enabled. Your query is sent to the chosen provider and, for SearXNG, its configured search engines. Results are unverified links, not confirmed jobs or application forms.

For general-web search enter https://freeserp.ai/ above. FreeSerp returns at most its top 100 candidates per phrase; indexed pages may be stale and can include non-jobs. Results are provided by FreeSerp. Local OpenSERP search is unavailable until at least one underlying search engine is approved in Waypoint's source permission registry. The provider runs its own browser and manages its own resources; Waypoint does not configure proxies or solve challenges. For Wiby enter https://wiby.me/ above. Its small, independent index is focused on older and personal websites, so job coverage may be limited. Wiby results are provided by Wiby.

    Supported formats and local tools

    Review text from UTF-8, Markdown, DOCX, and selectable-text PDFs. DOCX extraction includes numbered headers and footers, including variants that may not appear on every page. PDF text extraction requires pypdf; page preview additionally requires pypdfium2 and Pillow in the configured local Python runtime. Scanned PDFs need OCR for text. Single-frame PNG and JPEG images can be converted to PDF for attachments; review the result.

    Storage location

    By default Waypoint stores its workspace in your Windows user profile. Choosing another folder takes effect after restart; existing data stays in its original location and is not copied.

    Email connection

    Connect Gmail using your Google Desktop OAuth client JSON. Google will ask for mailbox read and send permissions. Credentials are stored with your Windows account using DPAPI. Connecting does not send email; in-app email delivery is still being developed.

    Alternatively, connect with a Gmail app password. Waypoint checks SMTP and IMAP authentication without reading or sending messages, then stores the credentials using Windows DPAPI.

    Checks total and unread inbox counts; no messages are opened.

    Sends a fixed test message to the connected app-password account. Check the mailbox before retrying if the result is uncertain.

    Local tools and setup

    Leave the path blank to detect an existing Python, or enter an absolute path. Set up a private PDF environment using this Python. This downloads pinned pypdf, pypdfium2 and Pillow packages from PyPI. Existing Python packages are not changed. Requires a compatible Python with venv and internet access.

    Checks local PDF dependencies without installing them.

    For a nonstandard installation, enter its soffice.com path. Leave blank to use automatic detection. This setting does not install LibreOffice or verify its operation.

    Checks for a Chromium browser, LibreOffice and a Python executable. Use Check PDF tools to verify the Python packages.

    Reports a current Windows GPU memory snapshot when available. It does not reserve memory.

    Starts an existing local Ollama installation if it is not already running. No model is loaded automatically.

    Downloads use Ollama’s configured model storage and can require substantial disk space and time. Existing models are left unchanged. Installation does not start the model.

    Local AI features require Ollama and one already-loaded model reporting up to 16 GiB on GPU and up to 2 GiB estimated model offload. Check local model shows its reported vision capability and loaded context. List installed models to start one using conservative memory checks; the model installer requires Ollama to be running. Memory snapshots cannot reserve resources. Form inspection can still offer limited exact-label suggestions without it.

    Application preparation

    Shortlist a job to prepare a draft or inspect its form. Inspection reads the public page and proposes profile mappings; it does not fill or submit it.

    A visible session lets you handle sign-in, CAPTCHA, and additional sections yourself. It closes after 10 minutes. Attaching a saved document creates a temporary local copy until the session closes; a crash can leave that copy behind. Do not submit unless you intend to apply.

    Lessons from form review

    Record a reviewed observation for future reference. Lessons are hints, not actions or proof that another form works the same way. A new lesson may be used during the next inspection; it does not change the review already open.

    Keep notes general; avoid personal details, answers, credentials and copied application content. Notes are stored encrypted and shown locally. If enabled below, the local model may receive the note as untrusted context; long or numerous notes may be omitted to fit the budget.

    Application records

    Preparation attempts are saved in the application-records folder inside your selected workspace. Records contain plaintext documents, answers and screenshots.

    Review before applying

    Waypoint has no application-submit feature. A website can still submit or transmit data during form interactions. Do not interact with real forms when an application must not be sent.
