# ATS-oriented CV checks: research checkpoint

Research date: 2026-10-28. These are independent open-source projects, not certifications of compatibility with any employer's ATS.

- [Open ATS](https://github.com/jlynshue/open-ats), commit `1fcff985e0cbcac065518dabebea1b96f1bb802a`, reports MIT licensing. Its PDF parser uses pdfplumber and warns that extraction order can degrade on multi-column pages. Its formatting analyzer applies heuristic penalties. Its package lists spaCy, NLTK and pandas among its dependencies. The tool was inspected, not installed or executed, and no code was copied.
- [ResumeFold](https://github.com/delta-dog/resumefold), commit `b7ab6411f26c967864716f7b0bb44905d8aca52a`, reports MIT licensing. Its checks include template structure and keyword review; its own checker notes that some checks rely on its own renderer's guarantees. Those guarantees cannot be assumed for arbitrary user-supplied templates. It was inspected, not installed or executed, and no code was copied.

Both project pages were read with Crawl4AI `0.9.4+superzip.portable2`, robots checks, a 30-second page timeout, no external model, and isolated task cache. Native captures are retained outside Git under `prototype-local/ats-research/`: `open-ats-native.json` (HTTP 200, SHA-256 `f7b8878390c7fd488c7545580e7fa82cda66956da352be1e8800042db44bcfd1`) and `resumefold-native.json` (HTTP 200, SHA-256 `ec12395cf05bf9692d88da05777f5465a2369864a723036ee40c4bc0314bab39`). GitHub API metadata, tree and license captures and selected exact source files are retained in the same ignored folder. No private CV was sent to either project.

Waypoint's initial diagnostic reuses its existing local PDF and DOCX extraction. It exposes a sample of reading order, literal frequent posting terms, and structural warnings for DOCX tables, text boxes and headers. It does not calculate a vendor ATS score, establish the relevance of every term, verify layout in arbitrary PDFs, or rewrite a document. A missing keyword must not be invented; review only truthful qualifications and the full rendered document. Position-specific editing, repeated checks after editing, and model-assisted full-page visual review remain to be integrated.
