## Efficient execution

Finish connected mechanisms before adding cosmetic options. Reuse existing
drivers, converters, grants, records and resource guards. Use one bounded local
model workload at a time, retain ownership-based cleanup and measure host/GPU
resources rather than assuming spare memory. Test changed behavior and genuine
failure paths first; run the required integration checks once at coherent
checkpoints. Reuse unchanged evidence with its scope, keep private data outside
Git, commit substantial batches on main and push infrequently. Do not replace
missing qualification with more documentation or a ceremonial zero-finding count.
