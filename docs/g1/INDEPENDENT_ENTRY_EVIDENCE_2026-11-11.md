## Production evidence

Recorded controls now retain their native origin, selector without the temporary
frame lease and ordered section-label path. Descriptors are read-only; only the
recorded driver can construct a pre-action field witness. Section-navigation
targets cannot provide a field witness. Current saved-page inventories expose
control kinds/identities and explicit omitted-field counts, without candidate
values. Successful entries publish values only after the existing command/native
readback and final field checks. File proof retains verified content identity.

After a failed action, a witness can obtain a bounded current screenshot and
text value. The observer checks document/frame identity, schema/origin, page
barriers, non-read requests and value stability across the screenshot. Changes
or missing evidence refuse the observation. The failure remains unverified,
keeps its original reason and cannot authorize retry, advancement or acceptance.
The current diagnostic value reader covers text controls; other control kinds
can retain a bound image without inventing a text value.

Schema 2 of the [evaluation contract](../FORM_EVALUATION.md) compares independent
expected values and stable control/section keys, including repeated labels.
Native proof, actual matching screenshot bytes and the expected answer are all
required. Unknown answers, missing/incorrect/unverified entries, ambiguous
controls and unmet required answers remain explicit. File comparisons use the
native-verified digest, not the filename. A final-review/workflow truth protocol
exists, but the general product does not yet emit the full native proof it
requires. Unit tests of that protocol are not real workflow success.

Schema 1 remains readable with its original narrower meaning; historical field
credit is never upgraded to value-level correctness. Expected answers are frozen
in controller data and are not sent to the local model.
