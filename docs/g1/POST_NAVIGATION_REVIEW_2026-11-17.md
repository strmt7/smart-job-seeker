# Post-navigation review evidence · 17 November 2026

A guarded section change can leave a read-only summary, a repeated section,
or a form that requires intervention. The rehearsal now retains that view
when it can recheck the same document, inspected form and replay activity
after capturing the image. A changed document or replay gap still stops the
run. This capture establishes what the browser observed at the stop and
leaves final review for independent verification.

Application history links the stopping section to its saved review view. The
view records its source section, image digest and explicit unverified
final-review state. The UI selects that exact view and retains the existing
image access checks.

When the selected model cannot start, the rehearsal saves an inspected page
view and the startup reason with entry disabled. It keeps the user's model
selection and only runs the read-only capture after the model admission path
has completed cleanup.

## Qualification

The fictional native fixture freezes twenty expected field values across five
successive sections. It exposes the final review summary only after the
required values match. The terminal submit control has a local sentinel and
no delivery path. The first run exhausted its 160-second fixture allowance.
The 420-second run verified all 16 fields in the first four sections and
reached its deadline during the fifth. The run with 660 seconds verified
12 fields across three sections, refused a field whose form state could no
longer be verified in section four, and closed the isolated browser.
Neither run established completion of the 20-field journey. The driver
now distinguishes document, form and native control changes in that check.

- A separate five-field fixture used one required field in each of five
  sections. All five values passed native readback, and the application
  recorded the read-only terminal view. The visible submit sentinel stayed
  unchanged, replay counters for blocked or unreplayed activity stayed at
  zero, and the browser closed. The contained run took 70.4 seconds.
- A separate native run refused invalid model settings. It saved one page
  with four observed fields and the exact startup reason. It attempted zero
  entries, made no request to the alternate local model endpoint, and
  verified the archived image digest.
- The Windows development build, warnings-denied Clippy, 1,469 Rust tests
  with 620 ignored, 172 UI scripts and 69 rendered checks passed. The
  terminal and startup-refusal states were inspected at narrow width and
  checked at 200% zoom.

The independent native tests use fictional inputs and deterministic test
callbacks. They qualify navigation, readback and capture in this scope.
