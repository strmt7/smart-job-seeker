# Redundant fit criteria experiment — 2026-10-30

The existing local model produced three criteria for a fictional listing requiring C and C++ programming experience: C, C++, and the broader phrase “programming experience”. The third criterion may duplicate the first two and affect their weight in the match estimate. The strengthened ignored live test checks that this redundant category is not counted and that an independent five-year experience requirement remains present. The current production prompt is known to fail the first check in the observed run.

An experimental instruction to avoid generic duplicates did not change the C/C++ result. Adding a Java/Python example produced two criteria in that case and retained the five-year requirement in a second fictional listing. However, the existing end-to-end semantic candidate comparison then failed twice after its permitted repair with invalid assessment text. A shorter version also failed that comparison with an invalid criterion source. Those prompt changes were removed; they are not a validated fix. After restoration, the semantic candidate comparison passed once. The result does not explain why the altered prompts failed, prove the baseline is generally reliable, or establish that generic criteria are always redundant.

Tests used the local `qwen3.5:9b` model, digest `c97eb11d70b1acdc88af01eef566c1fe4f7fbe93eb1afc06871132f293ff425a`, reported fully GPU resident with a 4,096-token context. Only fictional inputs were used. Future changes need broader cases and must retain genuinely independent requirements; silently dropping a criterion solely because it is broad is not justified by these observations.

## Advisory overlap review

A separate bounded local-model call now reviews the listing criteria after assessment. It returns criterion IDs only, without candidate facts, and the application validates the IDs. Suggestions do not remove criteria or alter the stored score. The user can temporarily exclude criteria to see their effect; these preview changes are not saved. Missing, invalid or unavailable reviews are reported rather than treated as a clean review. The listing is limited to 5,000 bytes and a shortened listing is disclosed.

The first probe identified the generic C/C++ criterion but incorrectly suggested removing both specific skills when an independent five-year requirement was present. A revised instruction passed four fictional comparisons: the generic C/C++ and German/English categories were flagged, while a five-year programming requirement and a separate nursing-license requirement were retained. These are small hand-selected cases, not evidence that the model reliably detects duplicate criteria. The existing fictional semantic candidate comparison also passed with the advisory call in place. A fixed-rubric test checks invalid IDs and verifies that review does not mutate the score.
