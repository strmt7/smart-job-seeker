# LibreOffice provisioning for Windows packaging — 2026-10-30

When no existing LibreOffice distribution is selected or discovered, the packager can now download the official x64 LibreOffice 26.8.2 MSI, stream at most 512 MiB, verify its pinned SHA-256 and extract it to a private `target/waypoint-office-*` directory with Windows Installer administrative extraction. `--libreoffice-msi` accepts the same pinned MSI for an offline build; `--libreoffice-dir` selects an existing distribution, and `--no-libreoffice` explicitly omits the converter. The MSI is not run before its digest is verified. Provisioning checks for at least 4 GiB of free staging space, requests no restart, limits extraction to 300 seconds and preserves the staging directory on failure because Windows Installer may still be active after a timeout. A failed download removes its partial MSI before the service starts. Successful packaging removes its owned staging directory after verifying the resolved path.

The [official checksum file](https://download.documentfoundation.org/libreoffice/stable/26.8.2/win/x86_64/LibreOffice_26.8.2_Win_x86-64.msi.sha256) and the [Windows package manifest](https://github.com/microsoft/winget-pkgs/blob/master/manifests/t/TheDocumentFoundation/LibreOffice/26.8.2.2/TheDocumentFoundation.LibreOffice.installer.yaml) agreed on MSI SHA-256 `ff4b911403b67ee9e6249f820f9782c44bb32c94fdaa45b0da53a8e419e5307a`. The raw checksum capture had SHA-256 `002e3fc16147cea8140dda67f2063021cf8798f830b26670d7d9fd06c2dbd9c4`; the raw manifest capture had SHA-256 `f41378f4b7e373d6b9fadfb666efc07256bcf24e8423d294ac20e7bbbc3a4740`. These captured native metadata files remain under `target` and may be removed by a clean build.

On this Windows host, the official 375,934,976-byte MSI was downloaded and matched the pinned digest. A full offline packaging run using that local MSI and cached Python/PDF packages succeeded, inventoried 19,417 LibreOffice files, and removed its staging directory. The resulting unsigned debug ZIP was approximately 537 MiB, SHA-256 `c64e9876b7e52ca64aa50b002fab33404a3aaee3084c098fcd37103cab9ac4cf`. A converter extracted from that ZIP converted a fictional DOCX through the app's integration test; a PDF reader extracted both expected passages. A subsequent direct provisioning check exercised the current no-restart extraction command. The checksum, size-limit and mismatched-local-MSI fixture tests passed.

These checks do not establish a clean-machine installation or automatic network-to-package run: the full packaging run used the local verified MSI. The package was made before the later no-restart and staging-cleanup guard refinements, which do not change its bundled files. LibreOffice still depends on the Windows Visual C++ runtime; Rust, MSVC and OpenSSL build-time provisioning, browser and Ollama installation, code signing and redistribution-license review remain incomplete. The result is a prototype, not a release. No employer site or application submission was involved.
