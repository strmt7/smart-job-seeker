# Local model application-page assessment — 2026-10-30

The application-page checker previously required one of a small fixed set of phrases before presenting a local vision model's positive judgment. It now asks for a separate text classification of bounded DOM text when the vision model identifies a possible application form. Both judgments must call it an application form and provide a short exact quote present in the captured page text. The result includes both quotes, remains explicitly unverified and viewport-limited, and always requires manual review. If text verification is unavailable, malformed, disagrees or cites text not in the captured page, the positive judgment is not corroborated. The model calls are separately prompted but use the same model and are not statistically independent; matching DOM text does not prove that the quote was visible or that the interpretation was correct.

The [initial two-vision run](application-check-two-vision-2026-10-30.txt) failed: the model classified a fictional product-support form as a possible application even after a second vision prompt. That version was not retained. A separate direct text probe classified fictional English and Italian job and support text correctly. In the [final combined-path run](application-check-vision-text-2026-10-30.txt), two fictional job forms in English and Italian were reported as possible application forms, while two fictional product-support forms were not corroborated. The Italian job heading is not in the former fixed phrase list. The local `qwen3.5:9b` model had digest `c97eb11d70b1acdc88af01eef566c1fe4f7fbe93eb1afc06871132f293ff425a`, was fully GPU-resident and used a 4,096-token context. The final live test took 4.16 seconds. Sampled free system RAM was approximately 22 GiB and dedicated GPU usage approximately 10.8 GiB; these are not measured peaks.

Six focused deterministic application-check tests passed; two browser tests were ignored in that run, and the four-page local vision test was run separately. Four fictional pages do not establish accuracy across languages, sites or models. Neither agreement nor a quoted excerpt proves a page is an application or that an application can be completed. No real employer page was visited, no fields were filled and no application was sent.
