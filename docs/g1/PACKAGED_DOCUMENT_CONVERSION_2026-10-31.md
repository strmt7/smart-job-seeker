# Packaged document conversion — 2026-10-31

The package builder can reuse the runtime from a caller-specified previous Waypoint ZIP. It checks the supplied package SHA-256, validates the runtime inventory and license, and verifies each copied runtime file. The final implementation checks the source package hash both before and after copying; fictional tests covered incorrect package hashes, unlisted files, damaged runtime files and a source changed during copying. The caller-supplied hash binds the input bytes but does not independently authenticate their publisher.

A debug package was built with LibreOffice copied from the host installation and the runtime reused from the previously checked ZIP. The package was 2,272,418,691 bytes, SHA-256 `d2c03d99eaa8bf4ece43d6c7dcd2b0e206008855ce8218f33765dea5560edaeb`; its manifest contained 13,931 LibreOffice files and 985 runtime files. It was extracted and installed into a new isolated folder under `target` using Windows PowerShell 5.1. The installer completed its before-and-after file checks. This full package was built before the later second source-hash pass was added; that additional pass was exercised with fictional fixtures, not another full-size package.

The installed Waypoint executable was started with a separate application-data and temporary directory. Its tool-status endpoint selected the bundled LibreOffice executable. A fictional three-paragraph DOCX was uploaded and converted through the app's background PDF conversion endpoints; the returned PDF was 21,160 bytes, SHA-256 `74cc42cc896f05b2283bf28d3bb3ed7f6dc6b801ac80c491e553834e70178ba9`. The bundled PDF tools extracted the expected text and rendered one page. A visual inspection found that the simple text was legible and did not visibly overflow. No real candidate material or application submission was used.

This is one simple document on one Windows host. It does not establish fidelity for complex templates, PDF editing, clean-host installation, the pinned LibreOffice MSI provisioning path, GPU inference, or runtime redistribution rights. The package and fictional output remain in ignored local `target` directories. GPU runtime redistribution and the complete dependency license inventory still require review before distributing a bundle.
