## Changes

- History classification can reconsider an ambiguous role or component after
  ordinary batches and verified answers complete. A recheck sees the native
  question and uses the same record resolver and independent answer audit. It
  cannot choose between multiple currently confirmed roles, clear a wrong
  subject, or transplant proof to a changed question.
- When the model proposes a supported exact number but omits an explicit unit,
  the native question leaf can supply one unambiguous literal unit. The archive
  preserves the raw proposal and separately records the bound quote. A heading
  alone cannot provide the unit, and neither conversions nor conflicting units
  qualify.
- Contact classification requests exactly one decision per offered field. A
  response with missing, repeated or unknown identities stays unresolved. The
  compatibility response still honors review flags, including those from an
  earlier reasoning pass. Saved values and the scoring oracle stay outside the
  classification prompt.
