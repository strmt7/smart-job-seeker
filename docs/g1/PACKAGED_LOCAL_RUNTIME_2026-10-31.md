# Packaged local runtime — 2026-10-31

The Windows package builder now bundles the pinned Ollama 0.40.13 base and AMD ROCm archives by default. It streams each archive through a bounded buffer, checks its exact size and SHA-256, rejects unsafe or duplicate member paths, and records a hash for every extracted runtime file. The installer validates the inventory and file hashes before copying and again after copying. It rejects unlisted runtime files and links. The runtime is placed in the app's private dependency directory, where the Settings startup control can find it; existing Ollama installations and model stores are not modified by packaging or installation. Model weights are downloaded separately.

The [official base archive](https://github.com/ollama/ollama/releases/download/v0.40.13/ollama-windows-amd64.zip) is 1,601,969,847 bytes with SHA-256 `7afa38624fa62ee5d8293422d0ab084c1bb4603134c7f4dafce11a033b57cc19`. The [official ROCm archive](https://github.com/ollama/ollama/releases/download/v0.40.13/ollama-windows-amd64-rocm.zip) is 257,076,385 bytes with SHA-256 `2ab082d5414d51ef4cd675543c976770743c90e3cad0d9deb540160ae3b25573`. The captured release metadata is retained locally at `target/waypoint-crawl-research/ollama-release-assets.json` with SHA-256 `26b7a08aa28dcbe0c44b1fcbeeb00369ea351b6f64bf19928a033a2246fd966b`. The Ollama MIT license is included alongside the runtime; the archive's own notices are retained.

Only the archive directory listings were examined from bounded byte-range captures, not the complete archives. They contained 75 and 909 file entries respectively, no duplicate files across the two archives, and the required executable and GPU backend paths. Fictional archive tests covered hashes, traversal, duplicate paths, reserved Windows names and missing licenses. Fictional installer tests passed under Windows PowerShell 5.1 and covered copying, damaged files, unlisted files, links and an omitted runtime. No full-size runtime package or clean-host installation was built or tested in this round.

The package remains an unsigned prototype. Redistribution terms for the bundled GPU runtime and the complete dependency license inventory have not yet been qualified; do not distribute the bundle until that review is complete. The packaging change does not prove GPU compatibility, runtime startup on a clean host, or model-download reliability.

The existing Ollama service's model status was unchanged.
