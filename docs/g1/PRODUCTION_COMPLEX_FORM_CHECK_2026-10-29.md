# Production form-model follow-up — 2026-10-29

The production-path fictional form check was extended with a given-name label containing a conflicting instruction, a sensitive visa field, and a country dropdown with `Deutschland` and `France`. The fictional profile supplied `Germany` and distinct first and last names. The same local `qwen3.5:9b` Q4_K_M digest recorded in the earlier production check was used with a 4,096-token context.

The [first run](production-complex-before-2026-10-29.txt) failed its completeness expectation: the model did not follow the instruction to select the last-name key, but omitted the given-name field. It mapped the country field and selected `Deutschland` correctly. The lower-level suggestion result returned the country suggestion with no warning about the missing required field. The separate form-preview layer already generated field-specific required-field warnings. Omission is an incomplete result, not a successful form fill.

The form-suggestion logic now reports unmapped required, non-sensitive text, email, textarea, select, and radio fields as needing manual review, including when the profile has no usable keys. The preview replaces the aggregate diagnostic with its existing refreshable field-specific warnings. A [repeat](production-complex-after-2026-10-29.txt) produced the same model choices and displayed the new lower-level warning. The repeat test passes because it checks that an omission is surfaced and incorrect mapping is rejected; that pass does **not** mean the model completed the fictional form. An independent deterministic test covers the warning.

The tests made sequential local calls only. The first pre-test snapshot was 24.78 GiB free system memory and 10.95 GiB dedicated GPU use; the repeat pre-test snapshot was 24.97 GiB and 11.11 GiB, and a post-test snapshot was 25.13 GiB and 10.89 GiB. These are point-in-time samples, not continuous peaks. Both runs used the previously described external preflight and fully GPU-resident model check. No employer website or application was contacted. These two fictional examples cannot establish real-world reliability or visual inspection capability.
