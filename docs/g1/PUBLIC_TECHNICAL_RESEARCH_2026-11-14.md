## Runtime behavior

The saved-page rehearsal has an explicit, initially unchecked **Research technical
issues online** option. After a failed native or visual control check, it can
perform one technical investigation through the already owned local model. The
original failed field and halted state remain unchanged. Advice cannot authorize
or retry an application action, supply candidate facts, or promote a learned rule.
Ordinary recorded previews and default rehearsals make no new research requests.

The model chooses schema-constrained search, read, finish or stop actions. A
separate broker independently checks URLs and known profile identifiers before
transport, including redirected document URLs. Only fixed issue classes, control
kinds and public platform families enter the research context: no candidate
labels, values, screenshots, personal application URLs or files. Public source
content and optional local reasoning are explicitly untrusted advisory inputs.

The transport reuses existing public-address, source-permission, robots, request,
response-size and time controls. It has anonymous HTTPS GET access, with no cookie
jar, candidate browser, upload, POST, approval or email capability. Admitted native
responses retain their raw bytes, headers, framing, status and SHA-256 digest in
the private application record. Model strategy/actions and conclusions retain
native diagnostics separately. Failure does not become an empty successful result.

An investigation admits at most two search queries and three reads, with at most
two conclusion-validation attempts and sixteen decisions. Each read is bounded
to twenty seconds, twelve native requests, one MiB per body and three MiB received.
The sixty-second overall check is cooperative between operations, not a hard
inference/DNS interrupt. Existing owned-worker cancellation and resource admission
still apply. No sustained memory or interruption-latency guarantee is claimed.
The model uses bounded excerpts; the original downloaded bytes remain available.
A conclusion requires exact short quotations from the actual excerpts offered to
the model. This checks quotation provenance, not semantic correctness or repair
success. Its state is `advice_available`, never a verified solution.

## Remaining scope

The initial free search backend is Wiby. Provider selection/fallback and reliable
technical-search recall remain open; direct model-selected public URLs are also
supported. HTML text extraction is bounded best effort, not browser rendering.
Pages requiring login or challenges remain unavailable. Advice is not automatically
applied to the halted form. Candidate-aware complete journeys, useful remediation,
representative held-out evaluation, independent final review and controlled
cross-site learning remain separate unfinished acceptance criteria. No real
application interaction, application email or submission is part of this work.
