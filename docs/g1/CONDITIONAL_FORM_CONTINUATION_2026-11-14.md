# Conditional form continuation — 2026-11-14

## Scope and change

Development-only, headless, fictional saved-form execution. The browser keeps
its OS-enforced no-network context. There was no employer-site interaction,
candidate upload, application or email submission.

Previously, a correctly entered field that revealed another ordinary question
was rejected as a changed schema. The strict API retains that behavior. The new
progressive API permits a narrowly verified additive transition: current native
scope/document/loader, unchanged original field descriptors, the same target
backend node and successful native value/image checks. Replacements, removals,
new walls, changed earlier values and non-read activity do not become successful
continuations. Logical evaluation identities never authorize an action.

After an addition, the application stops the old plan, captures the new view,
rechecks prior entries and obtains a fresh local-model plan. Previously verified
fields are not retyped. Four conditional replans bound the inspection; field,
section and dialog limits remain. Whole-view images use a separate numeric
range so later views cannot overwrite field evidence.

## Separate reasoning recovery

`Inference::generate_advice` supports an optional plain reasoning request.
Ollama uses no schema for that request and returns only its nonempty, naturally
completed final assessment, not its separate thinking field. Output is bounded
to 2048 UTF-8 bytes, with 768–2048 total output tokens; form recovery requests
1536. Cancellation, request guards, resident context and response observation
remain active. Unsupported adapters return no advice without a request.

Form mapping may spend one recovery pass per inspection after a valid empty
mapping response. It sends question descriptions and available contact-key
definitions, without candidate values or expected answers. A bounded assessment
can inform another schema-constrained decision. The original native response is
retained; failed/oversized reasoning retains the original review outcome with
an explicit warning. Cancellation aborts. Existing sensitivity, offered-key,
selector, value, native and visual checks still govern all resulting proposals.
An assessment is never a candidate fact or action authorization.

Native transport tests cover complete/missing/blank/truncated/oversized final
answers, observer retention, context/format controls, invalid budgets and
pre-connect cancellation. A model-identity change vetoes advice before and after
generation. An adversarial advice regression cannot inject unknown facts or
map a sensitive field, and private profile values never enter these prompts.

Current source passes 1,378 workspace tests, with 614 ignored, across 43 test
groups; Clippy and the Windows debug web/tray build pass. No dependency changes.
Native baseline evidence applies to its recorded source; new reasoning requires
its own actual-model result and does not inherit the native matrix's success.
