## Production changes

The technical question now states the actual anonymous issue class: failed native
readback, attachment-widget acceptance, or visual control identity/state. No
candidate label, value, image, personal URL or file enters public research.
The broker reuses the existing free FreeSerp and Wiby implementations, tries a
fallback after failure/empty results, retains every provider attempt and surfaces
incomplete search. Successful HTTP/JSON parsing does not establish relevance.

Static extraction uses the locked ISC-licensed `scraper 0.29.0` HTML5 parser,
with its license inventory regenerated. It preserves entities and inline code,
ignores structural navigation/hidden elements, resolves actual document links
and HTML bases, and supports unique visible fragments and literal focused views.
Missing/ambiguous sections, invalid bases, unsupported document fragments and
structural limits stay explicit. This is static document text, not rendered CSS
visibility, JavaScript execution, an arbitrary PDF reader or complete site coverage.
Limits: one MiB input, 100,000 nodes, depth64, 6,000-byte UTF-8 views and eight
retained references. The local model receives at most two 1,500-byte excerpts.
A task-local one-document cache reuses the same native response for another view;
new view metadata records the original body digest, scope, offset and truncation.
Privacy and request guards still apply before cached access. No global cache,
background worker or personal browser is introduced.

The actual action schema is included in the model prompt as well as sent to the
native runtime. Completed reads retain their focus argument. Reassessment sees
current actions and remaining budgets. Prompt packing preserves source excerpts
and native schemas, records omitted optional context and refuses an irreducible
oversized prompt. Repeated identical failed requests stop after two attempts;
four distinct unproductive actions also stop. The existing two-query/three-read,
sixteen-decision and two-conclusion-validation limits remain unchanged.

Conclusion failures now identify exact issues and observed word/byte counts.
A constrained repair offers at most three exact, bounded source passages per
offered source; the model must generate a fresh response. Original failed output
is retained. There is no silent quotation trimming, invented evidence, accepted
new candidate fact or relaxed validator. A quoted conclusion establishes source
provenance only: semantic support and usefulness remain separate questions.
Advice cannot authorize, retry a field or promote a learned rule.

These decisions follow the [official structured-output guidance](https://docs.ollama.com/capabilities/structured-outputs)
and the [parser's documented interfaces](https://docs.rs/scraper/0.29.0/scraper/).
Source pages were retained through the required isolated reader; package metadata
used native API bytes. An ambiguous diagnostic initially failed with and without
schema grounding; clarifying its question made both oneOf variants finish.
Therefore these runs do not prove that prompt grounding alone fixes decisions.
