# Form corpus binding and embedded inspection repair - 11 November 2026

This checkpoint starts R02's input/denominator contract and repairs a connected
native inspection defect. R02/R03 remain in progress. It does not establish broad
form coverage, held-out accuracy, general candidate-aware planning or readiness.

## Input and evaluation changes

The [form-evaluation contract](../FORM_EVALUATION.md) extends the existing compiled
settings/rehearsal qualifier with optional frozen-case metadata. Cases bind the
replay manifest, actual compiled fictional-profile bytes, family/partition and
expected answerability. Duplicate keys/IDs, development/held-out family or input
leakage, tuned holdouts and changed inputs are rejected. Native results expose
the profile digest and parse errors; expected answers are not sent to the model.

Accounting preserves omitted-field denominators and refuses to credit ambiguous
labels/observations. Unknown/unexpected entry or uncertainty is critical; only
uniquely matched native/visual field records receive credit. The explicit field
gate requires a nonzero denominator, every answerable field verified and no
unsafe/unexpected/ambiguous entry. Case-bound qualification fails an unmet gate.
The overall workflow remains `not_qualified`; neither field credit nor controller
collection completion establishes a completed application.

The private seed has **two development cases / zero held-out cases**: one known
fictional three-step form and an initial nine-control snapshot from one saved
real form. The latter is explicitly an initial native inventory, not full-form
truth. Unknown preferred-name, cover-letter, LinkedIn and salary answers remain
unknown in its declared fixture context. The planned representative corpus,
new held-out families, permission-receipt annotation, repeated-control identities
and aggregate/repeated model qualification are still open.

## Defect found and repaired

The first bound local-model journey collected **0/3** answerable fields. Native
entry stopped before model action with “form changed after inspection.” This was
an integration defect, not a demonstrated model decision error: embedded-frame
binding prefixed control selectors and section IDs after the native inspection
snapshot had recorded their old identities. An unchanged form then failed its
own freshness check.

`LiveForm::with_control_scope` now performs that exact namespace transformation
while preserving evidence only if the original snapshot was current. It retains
all original page barriers and completion reviews. Previously stale evidence is
explicitly invalidated; even reconstructing its old selector/section bytes later
cannot make it current. Legacy forms acquire no new inspection evidence. Later
schema, origin or review changes continue to block entry. No stability check,
visual criterion, source permission or consequential-action boundary was disabled.
