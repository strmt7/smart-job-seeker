# Licensing and reuse boundaries

This package contains original research summaries, a proposed implementation plan, schemas, fictional fixtures, UI reference drawings and generated concept imagery. It does not bundle competitor source trees, pretrained model weights or font files.

The future Waypoint application is proposed to use Apache-2.0 for its original code, subject to the repository owner's final licensing decision. G0 must add the actual LICENSE/NOTICE with correct ownership information and compatible dependency notices. Do not assume that this proposal relicenses any third-party material.

Each researched repository retains its own code/data/model/asset license. Public visibility is not a license. In particular, inspect AGPL obligations, Commons Clause, noncommercial terms and datasets separately. Source summaries are not a full legal or dependency audit. Confirm exact versions and license files before copying any component.

The working name Waypoint is not trademark- or domain-cleared. The design and examples are not affiliated with employers shown in other products. Fictional .example.invalid URLs in fixtures are intentionally non-operational.
