# Search and verification log

Research session: 25 September 2026. This is a bounded audit. Search discovery, documentation inspection, code-path inspection and runtime testing are distinct.

## Completed passes

1. Broad web/GitHub discovery: integrated job-search workbenches, local Ollama, resume builders, self-hosted trackers and auto-apply projects. Queried `job application self hosted` and `job auto apply stars:>100`; discarded unrelated software-scheduler hits.
2. License and implementation checks: README/tree/license review; direct raw license checks for disputed cases. Followed JobSpy and historical AIHawk redirects. Separated documented, planned and unknown functions.
3. Official commercial product/help comparisons: Simplify, Teal, Huntr, Jobright, LoopCV, AIApply, Scout and three adjacent proof/review services. No subscription purchase or login walkthrough.
4. User-requested topic expansion: `topic:jobseekers` returned 37 entries, all retained. Important additional sources include openroles, commandjobs, AfriApply, job-hunter, SwizJobs and Opportunity Bridge. Lower-depth topic hits remain discovery-only.
5. Targeted counterexample search: local/native Windows, grounded resumes, application receipts, proof/evidence and Rust. Found AI Job Hunter and AARG and revised the thesis substantially.
6. Targeted source/code search: inspected AI Job Hunter glossary and located applied-check/evidence paths at commit 593219e263ab21e3939ae1967c5ce54fcab9ace0. This is not a whole-repository source audit.
7. Feasibility research: public ATS API limits, platform restrictions, GPU model/runtime cards, Windows native GUI, Rust browser/document tooling, privacy/security/accessibility and optional inbox scopes. Sampled failure reports without treating them as reproduced bugs.
8. Scientific review: primary publication/abstract records for resume writing, networking, matching, multilingual classification, context effects, browser/desktop task evaluation and prompt injection. Distinguish peer-reviewed venues from the arXiv copies reviewed.
9. Synthesis: nine documented plan revisions, 12-item gap/counterexample ledger, Rust engineering plan and implementation contracts. Artifact generation and QA recorded separately in qa/.

## Retrieval failures and scope

An auxiliary Firecrawl agent failed due to authorization and returned no evidence. It is excluded from the evidence count. An arXiv identifier that resolved to an unrelated audio-visual paper was discarded. Cached web pages may predate the research date; code/data/model licenses need pinning before reuse. No current third-party application, target GPU runtime or Windows build was executed here.

## Search saturation, not omniscience

The major capability classes were searched repeatedly and important counterexamples changed the design. This does not establish that every relevant repository or paid feature on the internet was discovered. The 92 unique candidates include unverified leads; 33 annotated entries have varying review depth. Do not advertise those counts as audited or installed applications.
