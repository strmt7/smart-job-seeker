# Research-driven plan revisions

These are actual changes in this research session, not fabricated independent model trials.

## V1 — Initial platform framing

Before: Combine discovery, tailoring and tracking as an integrated app.

Evidence: Existing workbenches already cover much of this chain. [S01 S02 S05]

Revised decision: Use integrated platforms as baseline rather than claiming integration is new.

## V2 — License and dependency audit

Before: Treat open-source labels and self-hosting as sufficient.

Evidence: Commons Clause/noncommercial terms and cloud-dependent applying steps surfaced. [S03 S13 S14 S15 S23 S24]

Revised decision: Separate code, data, model, host and platform permissions.

## V3 — User broadened scope

Before: Exclude restricted/public-code projects entirely.

Evidence: User explicitly allowed public code alongside open source. [S13 S14 S15 S73]

Revised decision: Include these competitors; keep reuse restrictions, do not equate public visibility with reuse permission.

## V4 — Topic expansion

Before: Freshness, local saved jobs and humane criteria checks might differentiate.

Evidence: openroles and Opportunity Bridge provide direct counterexamples. [S67 S72 S76]

Revised decision: Add topic coverage and narrower end-to-end quality hypotheses.

## V5 — Closest competitor discovered

Before: A native local-first job platform appeared relatively differentiated.

Evidence: AI Job Hunter already spans Windows, local AI, research, materials, autofill and tracking. [S63 S64 S65]

Revised decision: Make it the main comparator; inspect glossary/code before asserting deficiencies.

## V6 — Rust requirement

Before: Tauri/React shell around a Rust service would be acceptable.

Evidence: User requires Rust; AARG also shows Rust grounding/iteration prior art. [S66 S95 S96 S97]

Revised decision: Select a Rust-native UI spike and typed modular architecture; reuse inference engines explicitly.

## V7 — Efficiency and model qualification

Before: A model file smaller than 16 GB could be treated as fitting.

Evidence: Context, browser/display memory, runtime reasoning controls and backend correctness alter the result. [S36 S38 S43 S90 S91 S99 S100]

Revised decision: Add aggregate VRAM, zero-offload, context recall and latency qualification with explicit performance targets.

## V8 — Scientific and commercial countercheck

Before: More applications, networking and learning analytics could be marketed as unique benefits.

Evidence: Existing commercial products cover them; scientific evidence supports narrow mechanisms, not a universal agent outcome claim. [S77 S78 S80 S81 S82 S86 S87 S88]

Revised decision: Prioritize valid applications and active effort; require blinded benchmarks and later a properly powered outcome study.

## V9 — Final scope/QA revision

Before: Concept artwork, mock UI and a blueprint could be mistaken for a working product.

Evidence: No repo was installed, target GPU benchmarked or production Rust binary built in this session. [S63 S66 S95]

Revised decision: Label mock data and all targets; deliver a traceable build specification, not a false completion claim.
